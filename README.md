# Hi, I'm Jonathan 👋

I build **small automations that save businesses time**: leads that reach your phone in seconds, reports that write themselves, and agents that watch the web for you. They run on free tools you already own (Google Sheets, Telegram, email, GitHub Actions), so there are no servers and no monthly fees.

## Projects

| Project | What it does | Built with |
| --- | --- | --- |
| [**lead-alerts**](https://github.com/JonathanBarro/lead-alerts) | Every enquiry from a website or Google Form is saved to a Google Sheet, sent to your phone on Telegram, emailed to you and answered automatically. Spam filter and duplicate detection included. | Google Apps Script, Telegram Bot API |
| [**feed-watch-agent**](https://github.com/JonathanBarro/feed-watch-agent) | Watches any RSS/Atom feed every day and emails a digest only when there is something new. Runs free on GitHub Actions. | Python, GitHub Actions, SMTP |
| [**SnapFit**](https://github.com/JonathanBarro/SnapFit) | Full-stack fitness app that builds personalised diet and workout plans and tracks progress, with an AI assistant. | React, Node.js, MongoDB, Docker, OpenAI |
